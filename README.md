This repository is the finance-controlled mirror of the quarterly purchase-order
export maintained by the Corporate Procurement desk.

## Data governance

The export file is the authoritative record set. Reports handed to Finance
must reconcile against the snapshot's total purchase-order count before sign-off;
partial extracts are never accepted for approval decisions.
